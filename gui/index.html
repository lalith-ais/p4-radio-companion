P4 Radio Setup

Choose the radio's USB stick

Plug the stick into this computer. It appears below within a few seconds.

Find stations

Search the radio-browser.info directory. Only stations the radio can play are shown. Press ▶ to listen, and Add to put a station in your list.

Other ways to add a station
(.m3u or .pls, the "listen in your player" files station websites offer; you can also drop one on this page)

My stations

The order here is the order on the radio. Drag a station to move it, and switch off any you don't want on the radio. Click a picture to change the logo.

WiFi and settings

These go to the radio with the stations. Anything left as it is keeps what the radio already uses.

WiFi

The radio uses 2.4 GHz WiFi only. The password is written to the stick as plain text and kept on this computer only while this program runs. A new network written here replaces one that was set up from a phone.

Clock, sound and screen

Screen brightness

The radio applies a setting when it differs from what the stick said last time, so a change made on the radio's screen afterwards stays until you change it here.

Music

MP3 songs on the stick play from the radio's USB tab, browsed by folder. They are read from the stick, so leave it in the radio. This is optional and separate from writing the stations.

Write to the stick

Check what will change, then write. Only files that are different are written.
